One micro-confession that was typed and never sent — a To: line and the unsent line itself, written exactly as it was typed.

## The confession

    To: the girl who sat behind me in tenth grade
    i wrote "i still think about the way you laughed at my joke about the periodic table" and deleted it because fifteen years later it still sounds like a lie i want to be true

## Run it

```sh
python3 main.py
```

Writes the two-part confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
